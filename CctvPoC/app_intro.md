# TVPlayer 应用介绍（华为应用市场 · 公开测试版 Beta）

**TVPlayer** 是一款面向 HarmonyOS 的电视直播应用，依托央视频直播源，为用户提供清晰、稳定、流畅的免费电视直播体验。

## 核心功能
- **海量频道**：内置 70+ 频道，涵盖 CCTV 全系列（CCTV-1 至 CCTV-17、CCTV-4K/8K、奥林匹克频道、CGTN）、中国教育台，以及全国 30+ 省级卫视（湖南、浙江、江苏、东方、北京等）。
- **极速切换**：分类导航 + 一键切换，秒级响应，长时间观看不掉线、不卡顿。
- **高清流畅**：基于 HLS 自适应码率，支持高清/超清画质，弱网自动缓冲恢复。
- **后台与锁屏播放**：支持息屏、锁屏及后台持续播放，锁屏界面显示当前频道名称与播放控制。
- **频道台标**：频道列表与控制系统展示对应频道图标，识别直观。

## 支持设备与能力差异
适配 HarmonyOS **手机、平板、PC（2in1 二合一）** 三种形态。

| 能力 | 手机 / 平板 | PC（2in1） |
|------|-----------|-----------|
| 重力感应自动横屏全屏 | ✅ 支持 | ❌ 不支持（无重力传感器，采用窗口模式自适应大屏） |
| 触摸手势滑动调亮度/音量 | ✅ 支持 | ❌ 不触发（无触摸屏，可用系统音量键/亮度设置调节） |
| 手动全屏沉浸式观看 | ✅ | ✅ |
| 窗口模式分栏（视频+频道） | ✅ | ✅ |
| 息屏 / 锁屏 / 后台播放 | ✅ | ✅ |

- **手机 / 平板**：支持重力感应横屏自动全屏、触摸手势滑动调节亮度与音量、息屏后台播放，体验与手机一致。
- **PC / 2in1**：因设备无重力传感器与触摸屏，不强制横屏旋转、触摸滑动手势不触发；采用窗口模式自适应大屏（视频 + 频道分栏），支持手动全屏沉浸式观看与系统音量调节。

## 使用说明
- 应用需联网（获取直播流与鉴权），建议在 Wi-Fi 或稳定网络下观看。
- 频道内容均来自央视频公开直播源，仅供个人学习与非商业观看。
