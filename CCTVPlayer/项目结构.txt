运行期依赖链（桌面）
CCTVPlayer.exe
  ├─ 启动 cctv-proxy.exe（同目录）── 读同目录 sapi_cache\ 提供 /sapi 资产与注入
  ├─ EnsureServedHtml()  → player.served.html（含 keygen_bg / ts_module_body / RJq7sO71JF 的 base64）
  ├─ WebView2 导航 127.0.0.1:18888/player  → Go 代理返回 served html
  └─ 页面内依次：cKey(ts_module_body) → auth → yspticket(RJq7sO71JF) → open/token
                → 签名(keygen_bg get_signature) → get-live-info → m3u8
                → hls.cmg.js + slim 解密 → MSE 播放
